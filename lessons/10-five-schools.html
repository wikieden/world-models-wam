第 10 章 · 世界模型五派：在哪个空间预测

▶ 打开本章可交互动画

本章回答：同样是"做了会怎样"，世界模型可以预测成什么样子？五派各自怎么训练、推理时怎么用、强在哪弱在哪？它们为什么越来越像？

对应原文：调研报告 §1.1、§2 W1–W5、§4 共性；CIS 6280 第 2 讲 我的笔记
本章缩写：RSSM = Recurrent State-Space Model（循环 / 状态空间 / 模型）；ELBO = Evidence Lower BOund（证据 / 下界）；KL = Kullback–Leibler divergence（KL 散度，衡量两个分布差多少）；MCTS = Monte Carlo Tree Search（蒙特卡洛 / 树 / 搜索）；MPC = Model Predictive Control（模型 / 预测 / 控制）；CEM = Cross-Entropy Method（交叉熵 / 方法，一种采样优化）；JEPA = Joint-Embedding Predictive Architecture（联合 / 嵌入 / 预测 / 架构）；EMA = Exponential Moving Average（指数 / 滑动 / 平均）；VAE = Variational AutoEncoder（变分 / 自编码器）；NeRF = Neural Radiance Field（神经 / 辐射 / 场）；3DGS = 3D Gaussian Splatting（三维 / 高斯 / 泼溅）；GNN = Graph Neural Network（图 / 神经 / 网络）。全部缩写见 附录 · 缩写与术语表

讲解

第一步：同一个问题，五种答案的形状（2026-11-20）

类比：问五个人"明天会怎样"。

  • 画家给你画一幅明天街景的画（像素，W4）；
  • 气象员给你几个数：气温 18 度、降水 30%（物理量，W5）；
  • 棋手只告诉你"明天对你有利还是不利"（价值，W2）；
  • 速记员在小本上记几个只有他自己看得懂的符号，需要时能还原成画（隐状态，W1）；
  • 老练的观察者说"会下雨、街上人少"，不画细节（特征，W3）。

都在预测明天，只是答案的形状不一样。世界模型也一样：\(p(\text{未来}\mid\text{历史},\text{动作})\) 里的"未来"可以是像素、隐状态、特征、任务信号或物理量（调研报告 §1.1）。

一句话：五派的区别在"未来"长什么样。

第二步：W1 隐状态和 W2 任务信号（2026-11-20）

W1 隐状态生成式（Dreamer 一系）：

  • 训练：RSSM 有确定性状态 \(d_t\) 和随机隐状态 \(z_t\)；loss 是序列 ELBO = 重建观测 + 预测奖励 + KL 项；
  • 用法：从真实状态出发，在模型里想象约 15 步，用 actor-critic 训练策略，梯度不碰真实环境；部署时只跑 actor，便宜；
  • Dreamer 4（2025）：放大到视频规模，只靠离线数据在 Minecraft 里拿到钻石；
  • 短板：需要奖励；策略会钻模型错误的空子。

W2 任务信号 / 价值等价（MuZero 一系）：

  • 训练：三个函数，表示 \(h_\theta\)、动力学 \(g_\theta\)、预测 \(f_\theta\)；从真实轨迹展开 \(K=5\) 步，loss 只有奖励、价值、策略三项，没有重建项；
  • 用法：每一步都在隐空间里做 MCTS（MuZero）或 MPPI 规划（TD-MPC2），推理时一定要跑世界模型；
  • 短板：只服务一个奖励函数，换任务就要重训。

一句话：W1 能画回去、在梦里练；W2 只记分数、每步都搜。

第三步：W3 特征和 W4 像素（2026-11-20）

W3 表征预测（JEPA 一系，V-JEPA 2-AC）：

  • 训练两阶段：先在互联网视频上自监督预训练 encoder（在特征空间预测被遮的部分，target encoder 用 EMA 防坍缩）；再冻结 encoder，用不到 62 小时的 DROID 机器人视频训约 300M 的动作条件 predictor；loss 是特征空间的 L1，含 teacher forcing 和 rollout 两项；
  • 用法：给一张目标图像编码成 \(z_g\)，用 CEM 搜动作序列让预测特征接近 \(z_g\)，执行第一步后重规划（MPC）；
  • 结果：两个实验室的 Franka 上零样本抓取放置；每个动作规划约 16 s （二手）；
  • 短板：目标只能用图像给；规划慢；画不出来，难调试。

W4 像素 / 视频生成（Genie、GameNGen、Cosmos 一系）：

  • 训练：先训 tokenizer（VAE 或 VQ）并冻结；再在 latent 上训动力学模型，条件是历史帧 + 动作；动作可以来自日志，也可以用隐动作（第 9 章）；长 rollout 稳定性是核心难点（条件帧加噪、Diffusion Forcing、Self Forcing）；
  • 用法：自回归生成帧，少步蒸馏到每帧 1–4 步；Genie 3 做到 720p、24 fps 实时交互；
  • 短板：最贵；"看着对"不等于"物理对"；不能直接出动作。

一句话：W3 只预测"会发生什么"不画出来；W4 把每个像素都画出来。

第四步：W5 空间与物理（2026-11-20）

  • 静态 3D：NeRF、3DGS 重建场景，渲染新视角，本身不预测动作后果；
  • 生成式 3D 世界：Marble（World Labs），比视频多了"转身回来还在"的保证；
  • 物理变量：GraphCast 预测全球天气，GNN 模拟器预测粒子和刚体；
  • 物理引擎：MuJoCo、Genesis，规则写死、状态完全可读，是"确定性特例"（CIS 6280 第 3 讲）。

和学习式模型的关系：物理引擎提供骨架，学习模型补规则外的残差。

一句话："世界"不必是像素；规则写死的物理引擎也是世界模型。

第五步：三条路线和越来越像的底座（2026-11-20）

按"要不要画回像素"可以分成三条路线（调研报告 §1.1 末尾，对应第 1、2 讲的线索）：

路线 流派 代价 换来什么
重建 W1、W4 贵（要能还原像素） 看得见、能当数据生成器
不重建 W3 省 容量全花在"会发生什么"上
只学决策需要的 W2 最省 最紧凑，但只服务一个目标

另外 W5 物理引擎是"规则写死"的特例。

越来越像（调研报告 §4）：

  1. 都是"先压缩（tokenizer / encoder），再在压缩空间里预测"；
  2. 生成器收敛到"latent 上的 flow matching / diffusion transformer"：Dreamer 4、GameNGen、Cosmos、DreamZero 都是这一类；
  3. 共同的敌人是复合误差（第 4 章第四步）；
  4. 共同的风险是策略钻模型的空子：模型以为成功、现实失败。

Dreamer 4 本质上是一个可交互的视频生成模型，同时又是用来训策略的世界模型，W1 和 W4 的边界在消失。

一句话：画不画回像素分出三条路，底座却越来越统一。

数学原理

  • ELBO：\(\log p(o)\ge\mathbb{E}_q[\log p(o\mid z)]-\mathrm{KL}(q\|p)\)，重建项 + KL 项，W1 用它的序列版本。
  • 价值等价：只要模型预测的奖励和价值对，隐状态不必对应任何真实状态（W2）。
  • CEM：采样一批动作序列 → 打分 → 取最好的一部分重新拟合分布 → 重复（W3 的规划器）。

公式清单

公式 派别
\(\mathcal{L}=\sum_t[-\log p(o_t\mid z_t,d_t)-\log p(r_t\mid z_t,d_t)+\beta\,\mathrm{KL}]\) W1 Dreamer
\(\mathcal{L}=\sum_{k=0}^{K}[\ell^r+\ell^v+\ell^p]\) W2 MuZero
\(\mathcal{L}=\|P_\phi(z_{\le t},a_{\le t})-z_{t+1}\|_1+\text{rollout 项}\) W3 V-JEPA 2-AC
规划目标 \(\min_a\|\hat z_{t+H}-z_g\|_1\) W3 推理
